# 강아지별·고양이별 메타버스 구축 계획

2026-11-04 · Alden Hwang

> Claude에게: 이 문서는 프로젝트 전체 계획이에요. 작업할 때는 "이번 주에 바로 할 일"과 "단계별 로드맵"의 현재 단계만 진행하고, 한 번에 한 가지씩 만들어 주세요. 사용자는 Claude Code 입문자라서 무엇을 왜 하는지 쉽게 설명해 주세요.

## 한눈에 보기

떠난 반려동물의 사진 3~5장과 성격·좋아하는 것을 입력하면, 그 아이를 닮은 3D 캐릭터가 '강아지별·고양이별'에서 계속 살아가고, 집사는 휴대폰 브라우저로 언제든 보러 가는 웹 메타버스예요.

- **누구를 위해**: 반려동물을 떠나보낸 보호자. 반려가구의 54.7%가 반려동물이 떠난 뒤 우울감을 겪고, 16.3%는 1년 넘게 일상이 힘든 중증 펫로스를 겪어요 (KB 2025 한국 반려동물 보고서).
- **핵심 경험**: 아이와 '대화'하는 게 아니라, 아이가 별에서 잘 지내는 모습을 '지켜보고' 쓰다듬고 간식을 주는 것.
- **만드는 방식**: 산사처럼 앱 설치 없는 웹 3D와 채널을 나눈 실시간 서버. 산사에 더해지는 건 사진을 3D로 바꾸는 단계와, 아이 정보를 보관하는 계정이에요.
- **첫 버전(MVP) 범위**: 아이 1마리 등록 → 3D 생성 → 별 1개에서 성격대로 생활 → 집사가 접속해 쓰다듬기·간식·사진 찍기. 채팅과 말하는 AI는 넣지 않아요.
- **기간과 비용**: 혼자 Claude Code로 약 3달이면 공개할 수 있고, 시작할 때 월 고정비는 Cloudflare 5달러 정도예요. 가장 먼저 확인할 건 "사진으로 만든 3D가 정말 우리 아이처럼 보이는가"예요.

## 사용자 경험 흐름

1. **들어오기**: 링크로 접속해 카카오나 구글로 로그인. 사진과 아이 정보를 보관해야 해서 계정이 필요해요.
2. **아이 등록**: 사진 3~5장(정면·옆모습·전신)과 아래 내용을 입력해요.
    - 이름, 강아지/고양이, 품종, 털색
    - 성격 태그(활발함·겁이 많음·애교쟁이·도도함 등)
    - 좋아하는 간식·장난감·습관(예: 배 보이고 뒹굴기)
    - 생일과 별이 된 날(선택)
3. **별 모습 만들기**: AI가 사진으로 3D 후보 2~3개를 만들면, 집사가 하나를 고르고 털색을 조금 다듬어요. "실제 복원이 아니라 기억을 담은 모습"이라고 함께 안내해요.
4. **별에 도착**: 무지개다리를 건너 별에 내려오는 짧은 연출, 아이만의 집과 자리가 생겨요.
5. **별에서 생활**: 집사가 없어도 아이는 성격대로 놀고, 낮잠 자고, 좋아하던 간식을 먹고, 다른 아이들과 어울려요. 별의 낮과 밤은 실제 시간과 같이 흘러요.
6. **보러 가기**: 집사가 접속하면 아이가 알아보고 달려와요. 쓰다듬기, 간식 주기, 사진 찍기, 편지 남기기.
7. **기념일**: 생일과 별이 된 날에만 알림, 작은 파티나 별 꾸미기 이벤트.

여러 집사가 같은 별에 있어도 채팅은 없어요. 다른 집사의 아이에게는 하트 하나만 보낼 수 있어요.

## 기술 구조

핵심은 사진을 3D로 바꾸는 단계이고, 나머지는 산사와 같은 구조예요.

```
[집사의 휴대폰·PC 브라우저]  Three.js로 그린 3D 별 화면, 설치 없이 링크로 접속
      │ HTTPS                         │ WebSocket (실시간)
      ▼                               ▼
[웹·API 서버]                    [실시간 별 서버]
 Cloudflare Workers               Cloudflare Durable Objects
 로그인·아이 등록·결제             별 채널 1개 = 객체 1개, 채널당 약 100명
 3D 생성을 맡기고 완료되면 알림     아이들 위치·행동을 접속자에게 전달
      │            │                 │              │
      ▼            ▼                 ▼              ▼
[3D 생성: Tripo API]  [저장소: R2 · D1]         [행동 두뇌]
 사진 → 3D → 네발 리깅   R2: 사진·3D 파일          성격 태그 → 행동 확률표
 완성 파일은 R2에 저장    D1: 계정·아이 정보·편지    LLM은 등록 때 1번만 사용
```

- **화면 (Three.js)**: 브라우저에서 3D를 그리는 가장 흔한 도구라 Claude Code가 잘 다뤄요.
- **실시간 별 서버 (Durable Objects)**: 객체 하나가 WebSocket 서버 역할을 해서 '별 채널 1개 = 객체 1개'로 만들어요. 산사도 Cloudflare 서비스로 서버 100여 개를 운영해요.
- **3D 생성 (Tripo API)**: 사진으로 3D를 만들고, 네발 동물(quadruped) 뼈대를 약 30초 만에 붙여 GLB로 줘요. Meshy의 자동 리깅 옵션은 사람형 기준이라 네발 동물엔 Tripo가 더 맞아요.
- **저장소 (R2·D1)**: R2는 큰 파일, D1은 계정·아이 정보 같은 표 데이터.
- **행동 두뇌**: 움직일 때마다 AI를 부르지 않아요. 등록할 때 LLM이 성격을 행동 확률표(예: 낮잠 30%, 공놀이 20%)로 한 번 바꿔 두고 그 표대로 움직여요.

## 단계별 로드맵

전체 11~14주. 각 단계는 관문을 통과해야 다음으로 넘어가요. 기간과 기준은 제안이에요.

| 단계 | 기간 | 할 일 | 통과 기준(관문) |
| --- | --- | --- | --- |
| 0단계 · 닮음 검증 | 1~2주 | 사진 5장으로 3D 만들기(Tripo·Meshy 비교), 네발 리깅으로 걷기·앉기 확인 | 보호자 5명 중 4명이 '그 아이 같다' |
| 1단계 · 나 혼자 보는 별 | 3~4주 | Three.js로 별 1개 + 아이 1마리, 성격 따라 움직이는 행동 5~8개, Cloudflare에 올려 휴대폰으로 접속 | 휴대폰에서 끊김 없이 돌아감 |
| 2단계 · 함께 사는 별 | 3~4주 | 로그인·아이 등록·자동 3D 생성, 채널을 나눈 실시간 별, 쓰다듬기·간식·사진·편지 | 등록부터 별 도착까지 10분 안 |
| 3단계 · 비공개 베타 | 4주 | 지인·반려 커뮤니티 30~50가족 초대, 펫로스 배려 문구·삭제 기능 점검 | 다시 찾아오는 가족이 있고 큰 불편이 없음 |
| 4단계 · 공개 출시 | 그 이후 | '별에 보내기' 결제·꾸미기 아이템, 기념일 이벤트·추억 영상, 장례식장 제휴·앱 출시 | - |

0단계에서 '닮았다'는 반응이 안 나오면 동화풍 캐릭터로 방향을 바꿔요.

## 비용 예측

시작할 때 월 고정비는 5달러부터이고, 비용은 '등록한 아이 수'에 따라 늘어요. 등록할 때 돈을 받으면 서버비 때문에 급하게 후원을 받을 일이 줄어요.

| 항목 | 쓰는 곳 | 예상 비용 |
| --- | --- | --- |
| Cloudflare Workers 유료 플랜 | 웹 서버·실시간 별 서버 | 월 최소 5달러. 요청 100만 건, 40만 GB-s 포함 |
| Durable Objects 초과분 | 접속자가 많아질 때 | 요청 100만 건당 0.15달러, 100만 GB-s당 12.5달러 |
| 사진 → 3D 생성 (Tripo H3.1) | 아이 등록 | 1회 0.10달러. 후보 3개면 약 0.30달러 |
| 자동 리깅 (Tripo) | 걷기·앉기용 뼈대 | 1회 25크레딧 (달러 환산은 가입 후 확인) |
| 도메인 | 서비스 주소 | 연 2~3만 원 안팎 (대략치) |

- 개발 기간에는 무료 플랜으로 충분해요(Durable Objects 무료 플랜 하루 요청 10만 건).
- WebSocket Hibernation(잠들기) 기능을 꼭 써서 서버비를 줄여요.
- 아이 1마리 원가는 천 원대로 추정해요.

## 펫로스 배려·윤리·개인정보

- 아이는 말하지 않아요. 대화형 AI나 '아이가 보낸 편지'는 넣지 않아요.
- "복원이 아니라 기억을 담은 모습"이라고 표시해요.
- "아이가 기다려요" 같은 죄책감 주는 알림은 쓰지 않고, 알림은 기념일에만(끌 수 있음).
- 아이는 아프거나 다시 떠나지 않아요. 돈을 안 내면 아이가 사라지는 구조도 없어요.
- '별에서 편히 쉬게 하기'로 작별할 수 있고, 추억 사진첩만 남겨요.
- 별 구석에 펫로스 상담 기관 안내를 둬요.
- 사진은 비공개 보관, 버튼 하나로 사진·아이 정보·계정을 한꺼번에 삭제.
- 3D 생성 때 사진이 외부 서비스(Tripo)로 전송된다는 걸 알리고 동의를 받아요. 개인정보 처리방침은 출시 전 전문가 확인.

## 수익 모델

등록 때 한 번 받고, 그 뒤는 원하는 사람만 작은 선물을 사는 구조. 매달 내는 구독은 추천하지 않아요.

| 상품 | 내용 | 가격 아이디어 |
| --- | --- | --- |
| 별 둘러보기 | 다른 아이들의 별 구경, 하트 보내기 | 무료 |
| 별에 보내기 (1회) | 사진으로 3D 생성, 평생 별에서 생활 | 9,900~19,900원 |
| 별 꾸미기 | 집·장난감·쿠션·계절 장식 | 개당 1,000~3,000원 |
| 추억 영상 카드 | 별에서 노는 15초 영상, 기념일마다 새로 | 3,000~5,000원 |
| 장례식장 제휴 (B2B) | 장례 패키지에 '별에 보내기' 포함 | 건당 정산 (협의) |

유튜브 채널에서 개발 과정을 보여주면 첫 사용자를 모으기 좋아요. 가격은 베타에서 직접 물어보고 정해요.

## 리스크와 대응

| 리스크 | 대응 |
| --- | --- |
| 3D가 닮지 않음 | 사진 여러 장, 후보 중 고르기, 털색 조절. 안 되면 동화풍 캐릭터로 |
| 움직임이 어색함(특히 고양이) | 네발 리깅 사용, 동작 5~8개로 시작, 동작을 모든 아이에게 공유 |

- [ ] 더 나은 모델을 네발(quadruped)로 리깅해서 GLB 파일 받기

- [ ] Claude Code로 빈 프로젝트를 만들고 GLB를 Three.js 화면에 띄우기
- [ ] Cloudflare 계정 만들기 (지금은 무료 플랜으로 충분)
- [ ] 서비스 이름 후보 3개 정하고 도메인 확인

Claude Code 첫 요청 예시:

```
Three.js로 웹페이지 하나를 만들어 줘. 풀밭과 하늘이 있는 작은 행성 위에
models/dog.glb 파일을 불러와서 올려 줘. 강아지는 천천히 돌아다니다가 가끔 앉아 쉬게 해 줘.
휴대폰에서도 부드럽게 돌아가야 하고, 내 컴퓨터에서 바로 열어볼 수 있게 실행 방법도 알려 줘.
```
