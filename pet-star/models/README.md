# 3D 파일 넣는 곳

우리 아이 3D 파일을 `dog.glb`라는 이름으로 이 폴더에 넣어 주세요.
파일이 없으면 화면에는 도형으로 만든 임시 강아지가 나와요.

- 이 폴더의 `.glb` 파일은 GitHub에 올라가지 않아요(`.gitignore`). 이 저장소는 공개라서, 사진으로 만든 아이 모습이 남에게 보이지 않게 막아 뒀어요.
- 크기와 위치는 자동으로 맞춰요.
- Tripo에서 네발(quadruped)로 리깅한 파일이면 뼈대를 찾아서 걷기·앉기를 코드로 움직여요. 걷기 동작이 파일에 없어도 돼요.
- 아이가 뒤나 옆으로 걸으면 `../src/config.js`의 `modelTurnDegrees`를 바꿔 주세요.
- 다른 이름(예: `cat.glb`)을 쓰려면 `../src/config.js`의 `modelUrl`도 바꿔 주세요.
