# 강아지별 · 첫 화면 (0단계)

이번 주 목표 **"내 컴퓨터 브라우저에서 3D 강아지 한 마리가 걸어 다니는 것을 보기"**를 위한 첫 화면이에요.
전체 계획은 [PLAN.md](PLAN.md)에 있어요.

## 지금 되는 것

- 풀밭, 나무, 꽃, 바위, 구름이 있는 작은 별과 하늘
- 아이가 별 위를 천천히 돌아다니다가 가끔 앉아서 쉬어요. 나무와 바위는 피해 가요.
- 화면을 끌면 둘러보고, 두 손가락(컴퓨터는 마우스 휠)으로 가까이·멀리 볼 수 있어요.
- "별 전체 보기" 버튼으로 별 전체를 보고, 다시 누르면 아이 곁으로 돌아와요.
- `models/dog.glb` 파일이 있으면 그 모델을 쓰고, 없으면 도형으로 만든 **임시 강아지**가 나와요.

## 내 컴퓨터에서 열어 보기

파일을 더블클릭해서 열면 브라우저가 보안 때문에 코드와 3D 파일을 막아요.
그래서 내 컴퓨터에 **작은 서버**를 잠깐 켜고 그 주소로 열어요. 어렵지 않아요.

1. 이 저장소를 내 컴퓨터로 받아요.
   - GitHub 페이지에서 `Code` → `Download ZIP`으로 받아 압축을 풀거나,
   - 터미널에서 `git clone https://github.com/mardien-vosse/simple-memo-app.git`
2. 터미널(맥: 터미널 앱, 윈도우: PowerShell)을 열고 `pet-star` 폴더로 이동해요.
   ```
   cd simple-memo-app/pet-star
   ```
3. 작은 서버를 켜요.
   - 맥: `python3 -m http.server 8000`
   - 윈도우: `python -m http.server 8000`
   - 파이썬이 없고 Node.js가 있다면: `npx serve -l 8000`
4. 브라우저에서 **http://localhost:8000** 을 열어요.
5. 다 봤으면 터미널에서 `Ctrl + C`를 눌러 서버를 꺼요.

> Three.js(3D를 그리는 도구)는 인터넷에서 불러오기 때문에 인터넷이 연결되어 있어야 해요.

### 휴대폰으로 보기

1. 컴퓨터와 휴대폰을 **같은 와이파이**에 연결해요.
2. 위 3번처럼 서버를 켠 채로 컴퓨터의 내부 IP 주소를 확인해요.
   - 맥: 시스템 설정 → Wi-Fi → 연결된 와이파이의 `세부사항` → IP 주소
   - 윈도우: PowerShell에서 `ipconfig` → `IPv4 주소`
3. 휴대폰 브라우저에서 `http://IP주소:8000` (예: `http://192.168.0.12:8000`)을 열어요.
   방화벽이 허용할지 물어보면 허용해 주세요.

## 우리 아이 3D 파일 넣기

1. Tripo(또는 Meshy)에서 사진으로 만든 모델을 **네발(quadruped)로 리깅**해서 GLB 파일로 받아요.
2. 파일 이름을 `dog.glb`로 바꿔서 `models` 폴더에 넣어요.
3. 브라우저를 새로고침해요.

알아 두면 좋은 것:

- **크기와 위치는 자동으로 맞춰요.** 모델이 아주 크거나 엉뚱한 곳에 있어도 별 위에 알맞게 서요.
- **아이가 뒤나 옆으로 걸으면** `src/config.js`의 `modelTurnDegrees`를 `180`, `90`, `-90` 중 하나로 바꿔 보세요.
- **걷기 동작**: 파일 안에 이름에 `walk`가 들어간 동작이 있으면 걸을 때 재생하고, `sit`·`idle`·`rest`가 들어간 동작은 쉴 때 써요.
  동작이 없는 파일이면 몸 전체를 살짝 흔들며 움직여요. 리깅할 때 걷기 애니메이션도 함께 받으면 훨씬 자연스러워요.
- 고양이라면 `cat.glb`로 넣고 `src/config.js`의 `modelUrl`을 `'models/cat.glb'`로 바꿔요.
- 휴대폰에서 빨리 열리도록 파일은 가능하면 10MB 이하가 좋아요.
- 불러오는 데 문제가 있으면 화면 아래에 안내가 뜨고, 자세한 이유는 브라우저 개발자 도구(F12)의 `Console`에 나와요.

## 쉽게 바꿀 수 있는 것 (`src/config.js`)

| 항목 | 뜻 |
| --- | --- |
| `name` | 화면 위 이름표에 보이는 아이 이름 (지금은 예시로 '별이') |
| `modelUrl` | 3D 파일 위치 |
| `modelTurnDegrees` | 모델이 바라보는 방향 고치기 |
| `bodyLength` | 별 위에서 아이 크기 |
| `walkSpeed` | 걷는 속도 |
| `BEHAVIORS` | 다음 행동을 고르는 확률표 (산책 65, 앉아 쉬기 35) |
| `seed` | 나무·꽃 배치를 정하는 숫자. 바꾸면 별 모습이 달라져요 |

## 파일 구성

| 파일 | 하는 일 |
| --- | --- |
| `index.html` | 화면 틀: 이름표, 버튼, 안내 문구 |
| `src/config.js` | 아이 이름, 3D 파일 위치, 속도, 행동 확률표 (여기만 고쳐도 돼요) |
| `src/main.js` | 모든 것을 모아 매 순간 화면을 그리는 시작점 |
| `src/world.js` | 별, 풀, 꽃, 나무, 바위, 구름, 하늘, 빛 |
| `src/pet.js` | 아이 모습(GLB 또는 임시 강아지)과 걷기·앉기 동작 |
| `src/brain.js` | 행동 두뇌: 확률표로 다음 행동 고르기, 둥근 별 따라 걷기, 나무 피하기 |
| `src/camera.js` | 두 가지 보기와 손가락·마우스 조작 |
| `models/` | 우리 아이 3D 파일을 넣는 곳 |

## 휴대폰에서 가볍게 돌아가도록 한 것

- 나무와 바위는 한 덩어리로 합치고, 풀과 꽃은 같은 모양을 복사해 그려요. 한 화면을 그릴 때 32번만 그려요.
- 진짜 그림자를 계산하는 대신 발밑에 동그란 그림자를 그려요.
- 아주 촘촘한 휴대폰 화면도 선명도는 2배까지만 그려요.
- 다른 탭에 다녀와도 아이가 순간이동하지 않아요.
- 가상 아이폰 화면과 컴퓨터 화면에서 오류 없이 돌아가는 것을 확인했어요.
