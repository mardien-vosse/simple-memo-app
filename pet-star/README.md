# 강아지별 (0~1단계)

0단계 "사진으로 만든 3D가 우리 아이처럼 보이는가"와 1단계 "별 1개 + 아이, 성격 따라 움직이는 행동 5~8개"를 위한 화면이에요.
전체 계획은 [PLAN.md](PLAN.md)에 있어요.

## 지금 되는 것

- 풀밭, 나무, 꽃, 바위, 구름이 있는 별과 하늘. 반지름 24의 큰 별이라 아이 300마리가 넉넉하게 지내요.
- **별이의 집**: 크림색 벽, 산호색 지붕, 둥근 문, "별이네 집" 문패, 문 앞 방석과 밥그릇
- **행동 7가지**: 산책, 킁킁 냄새 맡기, 두리번거리기, 앉기, 엎드리기, 낮잠, 집에 가기
  - 자세는 하나를 푼 뒤 다음 자세를 해요. 낮잠은 엎드린 뒤 자고, 깬 뒤에 일어나요.
  - 집에 가면 방석에서 바깥을 보고 엎드려 쉬다가 잠들어요. 이때 카메라는 별이 앞쪽으로 돌아가서 집 벽에 가리지 않아요.
- **표정**: 2~6초마다 눈을 깜빡이고(가끔 두 번), 엎드리면 졸린 눈, 낮잠 자면 눈을 꼭 감아요.
  걸을 때는 주로 앞을 보다가 가끔 곁눈질하고, 멈춰 있을 때는 주변을 둘러보거나 집사(카메라)를 바라봐요.
- **이웃 아이들 299마리**: 강아지와 고양이, 여러 털색과 크기, 성격(활발함·느긋함·호기심)마다 다른 행동 확률표로 움직여요.
  지금은 **연습용**이고, 2단계에서 실시간 서버가 생기면 실제로 접속한 집사들의 아이로 바뀌어요. 수는 `config.js`의 `neighbors`로 바꿔요.
- 화면을 끌면 둘러보고, 두 손가락(컴퓨터는 마우스 휠)으로 가까이·멀리 볼 수 있어요.
- "별 전체 보기" 버튼으로 별 전체를 보고, 다시 누르면 아이 곁으로 돌아와요.
- `models/dog.glb` 파일이 있으면 그 모델을 쓰고, 없으면 도형으로 만든 **임시 강아지**가 나와요.
- Tripo에서 네발로 리깅한 모델은 뼈대를 자동으로 찾아서 걷고, 앉고, 엎드리고, 꼬리를 흔들어요.
  앉는 각도와 엎드리는 높이는 아이 체형에 맞춰 자동으로 계산해요(다리가 짧으면 덜 세워요).
- 털 사진에서 두 눈과 코를 찾아요. 사진을 찍을 때 고개를 돌린 모습이 3D에 굳어 있으면(별이는 약 50도) 바로잡고, 그 눈 위에 털색 눈꺼풀을 붙여요.
- 사진으로 만든 모델에는 은은하게 퍼지는 빛을 더해서 털색이 사진처럼 밝게 보여요.

## 내 컴퓨터에서 열어 보기

파일을 더블클릭해서 열면 브라우저가 보안 때문에 코드와 3D 파일을 막아요.
그래서 내 컴퓨터에 **작은 서버**를 잠깐 켜고 그 주소로 열어요. 어렵지 않아요.

1. 이 저장소를 내 컴퓨터로 받아요.
   - GitHub 페이지에서 `Code` → `Download ZIP`으로 받아 압축을 풀거나,
   - 터미널에서 `git clone https://github.com/mardien-vosse/simple-memo-app.git`
2. 터미널(맥: 터미널 앱, 윈도우: PowerShell)을 열고 `pet-star` 폴더로 이동해요.
   ```
   cd simple-memo-app/pet-star
   ```
3. 작은 서버를 켜요.
   - 맥: `python3 -m http.server 8000`
   - 윈도우: `python -m http.server 8000`
   - 파이썬이 없고 Node.js가 있다면: `npx serve -l 8000`
4. 브라우저에서 **http://localhost:8000** 을 열어요.
5. 다 봤으면 터미널에서 `Ctrl + C`를 눌러 서버를 꺼요.

> Three.js(3D를 그리는 도구)는 인터넷에서 불러오기 때문에 인터넷이 연결되어 있어야 해요.

### 휴대폰으로 보기

1. 컴퓨터와 휴대폰을 **같은 와이파이**에 연결해요.
2. 위 3번처럼 서버를 켠 채로 컴퓨터의 내부 IP 주소를 확인해요.
   - 맥: 시스템 설정 → Wi-Fi → 연결된 와이파이의 `세부사항` → IP 주소
   - 윈도우: PowerShell에서 `ipconfig` → `IPv4 주소`
3. 휴대폰 브라우저에서 `http://IP주소:8000` (예: `http://192.168.0.12:8000`)을 열어요.
   방화벽이 허용할지 물어보면 허용해 주세요.

## 우리 아이 3D 파일 넣기

1. Tripo(또는 Meshy)에서 사진으로 만든 모델을 **네발(quadruped)로 리깅**해서 GLB 파일로 받아요.
2. 파일 이름을 `dog.glb`로 바꿔서 `models` 폴더에 넣어요.
3. 브라우저를 새로고침해요.

> `models` 폴더의 `.glb` 파일은 GitHub에 올라가지 않아요. 이 저장소는 공개라서, 사진으로 만든 아이 모습이 남에게 보이지 않게 막아 뒀어요.
> 그래서 저장소를 새로 받으면 임시 강아지가 나와요. 아이 파일은 따로 보관해 주세요.

알아 두면 좋은 것:

- **크기와 위치는 자동으로 맞춰요.** 모델이 아주 크거나 엉뚱한 곳에 있어도 별 위에 알맞게 서요.
- **아이가 뒤나 옆으로 걸으면** `src/config.js`의 `modelTurnDegrees`를 `180`, `90`, `-90` 중 하나로 바꿔 보세요.
- **걷기 동작**: 파일 안에 이름에 `walk`가 들어간 동작이 있으면 그걸 재생하고, `sit`·`idle`·`rest`가 들어간 동작은 쉴 때 써요.
  동작이 없어도 Tripo 네발 뼈대가 있으면 코드로 직접 걷고 앉아요. 뼈대도 동작도 없으면 몸 전체를 살짝 흔들며 움직여요.
- 고양이라면 `cat.glb`로 넣고 `src/config.js`의 `modelUrl`을 `'models/cat.glb'`로 바꿔요.
- 휴대폰에서 빨리 열리도록 파일은 가능하면 10MB 이하가 좋아요.
  이번 시츄 모델은 털 사진을 4096에서 2048 크기로 줄이고, 면 수를 9만 8천 개에서 4만 4천 개로 줄여서 6.8MB를 2.4MB로 만들었어요. 모습은 거의 그대로예요.
- 불러오는 데 문제가 있으면 화면 아래에 안내가 뜨고, 자세한 이유는 브라우저 개발자 도구(F12)의 `Console`에 나와요.

## 쉽게 바꿀 수 있는 것 (`src/config.js`)

| 항목 | 뜻 |
| --- | --- |
| `name` | 화면 위 이름표에 보이는 아이 이름 (지금은 예시로 '별이') |
| `modelUrl` | 3D 파일 위치 |
| `modelTurnDegrees` | 모델이 바라보는 방향 고치기 |
| `bodyLength` | 별 위에서 아이 크기 |
| `walkSpeed` | 걷는 속도 |
| `BEHAVIORS` | 별이가 다음 행동을 고르는 확률표 (산책 30, 킁킁 12, 두리번 10, 앉기 14, 엎드리기 12, 낮잠 8, 집 14) |
| `planetRadius` | 별의 크기 (24면 300마리가 넉넉해요) |
| `neighbors` | 함께 사는 연습용 이웃 아이 수 (0이면 별이 혼자) |
| `seed` | 나무·꽃 배치를 정하는 숫자. 바꾸면 별 모습이 달라져요 |

## 파일 구성

| 파일 | 하는 일 |
| --- | --- |
| `index.html` | 화면 틀: 이름표, 버튼, 안내 문구 |
| `src/config.js` | 아이 이름, 3D 파일 위치, 속도, 행동 확률표 (여기만 고쳐도 돼요) |
| `src/main.js` | 모든 것을 모아 매 순간 화면을 그리는 시작점 |
| `src/world.js` | 별, 풀, 꽃, 나무, 바위, 구름, 하늘, 빛, 별이의 집 |
| `src/pet.js` | 아이 모습(GLB 또는 임시 강아지), 자세(걷기·앉기·엎드리기·낮잠·킁킁), 시선, 눈 깜빡임 |
| `src/brain.js` | 행동 두뇌: 확률표로 다음 행동 고르기, 자세 바꾸기 순서, 둥근 별 따라 걷기, 나무 피하기, 집 찾아가기 |
| `src/neighbors.js` | 이웃 아이들: 성격별 확률표, 강아지·고양이 모양, 보이는 아이만 한꺼번에 그리기 |
| `src/camera.js` | 두 가지 보기와 손가락·마우스 조작 |
| `models/` | 우리 아이 3D 파일을 넣는 곳 |

## 휴대폰에서 가볍게 돌아가도록 한 것

- 별 표면을 36조각으로 나눠서, 카메라에서 보이는 쪽 조각의 풀·꽃·나무만 그려요.
- 이웃 아이들은 몸의 부위마다 같은 모양을 한꺼번에 복사해 그려요(299마리를 10번 정도로).
  별 뒤편에 있어서 안 보이는 아이는 그리지 않고, 움직임 계산도 4번에 1번만 해요.
- 아이 곁에서 볼 때 한 화면에 삼각형 약 11만 개, 별 전체를 볼 때 약 26만 개예요. 이웃 아이 300마리의 움직임 계산은 한 장면에 약 1ms예요.
- 진짜 그림자를 계산하는 대신 발밑에 동그란 그림자를 그려요.
- 아주 촘촘한 휴대폰 화면도 선명도는 2배까지만 그려요.
- 다른 탭에 다녀와도 아이가 순간이동하지 않아요.
- 가상 아이폰 화면과 컴퓨터 화면에서 오류 없이 돌아가는 것을 확인했어요.

### 0단계에서 알게 된 것

- 사진이 엎드리거나 앉은 자세뿐이면 그대로 3D로 만들 수 없어요(그 자세로 굳어서 걷지 못해요).
  그래서 사진 3장을 참고해 AI로 "네 발로 서 있는 옆모습 전신" 사진을 먼저 만들고, 그 사진으로 3D를 만들었어요.
  2단계 등록 화면에서는 서 있는 전신 사진을 꼭 올려 달라고 안내하면 이 단계를 줄일 수 있어요.
- Tripo 공식 API 가격은 사진→3D가 20~30크레딧(0.2~0.3달러), 네발 리깅이 25크레딧(0.25달러)이에요(1크레딧 = 0.01달러).
  계획서의 0.10달러보다 조금 비싸지만, 아이 1마리 원가가 천 원대라는 계획은 그대로예요.
