# 스팀펑크 로또 6/45 추첨기 (실사풍 3D)

황동과 유리로 만든 스팀펑크 추첨기를 Three.js(WebGL)로 모델링하고, 구슬 45개의 움직임은 직접 만든 물리 엔진으로 계산하는 웹 앱입니다.

## 실행

- `lotto/index.html`을 브라우저(Chrome, Edge, Safari, Firefox 최신판)로 열면 됩니다. 서버나 인터넷 연결이 필요 없습니다.
- 그래픽 카드가 있는 PC나 맥에서 가장 보기 좋습니다. 느린 기기에서는 화질을 자동으로 낮춥니다.

| 조작 | 동작 |
| --- | --- |
| 레버 클릭 / `송풍 시작` / `Enter` | 송풍기를 켜고 끕니다 |
| `번호 뽑기` / `Space` | 배출구를 열어 구슬 하나를 뽑습니다 (충분히 섞인 뒤) |
| `자동 추첨` | 섞은 뒤 6개와 보너스 1개를 차례로 뽑습니다 |
| 드래그 / 휠 | 시점 회전 / 확대 |
| `M` / `D` | 음소거 / 물리 디버그 정보 |

## 물리 (src/physics.js)

- **구슬**: 지름 8cm, 속이 빈 플라스틱 구(관성모멘트 ⅔mr²)입니다. 위치, 속도, 각속도, 회전(쿼터니언)을 가진 3D 강체이며 600Hz 고정 스텝으로 적분합니다.
- **공기**
  - 송풍구 제트는 흐름함수 `ψ = Ψ₀·ξ·e^(−ξ²)`의 회전(curl)이라 발산이 0입니다. 위로 갈수록 퍼지며 약해집니다.
  - 제트 축의 흔들림, 기울기, 맥동, 돌풍을 더하고, 2D 와도 난류 모드를 겹칩니다. 요동은 OU 확률 과정이고 시드는 `crypto` 하드웨어 난수입니다.
  - 벽 경계층에서는 벽으로 들어가는 성분을 제거해 공기가 벽을 따라 흐르게 합니다.
- **힘**: 상대속도에 대한 이차 항력(Cd 0.47), 부력, 마그누스 힘(스핀비 포화), 공기에 의한 회전 감쇠를 받습니다.
- **충돌**: 구슬끼리, 원통 벽, 앞뒤 유리, 배출 깔때기 모두 반발계수, 쿨롱 마찰, 접촉점 회전을 반영한 순차 충격량으로 처리합니다.
- **배출**: 게이트가 열린 동안 바닥 깔때기로 처음 들어온 구슬이 뽑힙니다. 바깥 경로(튜브 → 레일 → 컵)는 구르는 중공 구의 가속도 `0.6·g·sinθ`, 구름 저항, 범퍼와 스토퍼 반발로 움직입니다.

### 무작위성 검증

`node tests/test-draw.js <횟수> <시드> <섞는시간>`으로 확인할 수 있습니다. 매번 **같은 초기 배치**에서 바람 시드만 바꿔 뽑는 가혹한 조건이며, 45개 번호의 빈도를 카이제곱으로 검정합니다. 실제 앱은 초기화할 때마다 배치도 무작위입니다.

## 개발

```bash
cd lotto
npm install
npm run build      # src → dist/lotto.js (하나의 파일로 번들)
npm run dev        # 수정하면 자동으로 다시 빌드
npm test           # 추첨 공정성 테스트 (200회)
```

- `src/main.js`: 렌더링 루프, 구슬 배달 애니메이션, UI
- `src/scene.js`: 기계 모델링, 재질, 조명
- `src/textures.js`: 구슬 라벨, 대리석, 금속 패티나, 명판, 배경 등 절차적 텍스처
- `src/audio.js`: WebAudio 합성 사운드
- `src/physics.js`: 물리 엔진 (Node에서도 동작)
